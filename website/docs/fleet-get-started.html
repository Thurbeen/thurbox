Get started with Fleet

Fleet runs on its own, with no thurbox. These steps take it from nothing to a coding agent working on a Task. You need tmux (psmux on Windows), git, and a coding-agent CLI that is installed and logged in (Agents).

1. Install Fleet # 

curl -fsSL https://raw.githubusercontent.com/Thurbeen/thurbox/main/scripts/install.sh | sh -s -- --fleet-only

This puts fleet, runtime-mux and workspace-git in ~/.local/bin. Windows, a 2.x note and a service for fleet up are on Install Fleet.

2. Set it up and start the manager # 

fleet init     # writes ~/.config/fleet/config.toml, offline
fleet doctor   # checks each agent's program and the runtime
fleet up       # the manager: keep it running in its own terminal

fleet up keeps every Task moving until you press Ctrl+C. The sessions keep running when it stops, and the next fleet up picks them up again.

3. Apply a first Task #

A Task is a JSON file. This one runs Claude Code in a new worktree of a local repository:

{
  "apiVersion": "fleet/v1alpha1",
  "kind": "Task",
  "metadata": {"name": "fix-login"},
  "spec": {
    "harness": "claude",
    "brief": "Fix the login redirect and run the tests.",
    "workspace": ["git+file:///home/me/app"],
    "dispatch": true
  }
}
fleet apply -f fix-login.json

harness names the agent, brief is its first prompt, and workspace lists what it works in (file:// for a directory as it is). Nothing starts while dispatch is false. Every field is in the Task resource.

4. Follow it, talk to it, read its result # 

fleet list task                          # every Task and its phase
fleet watch --json                       # one event per change, until Ctrl+C
fleet send fix-login "Run the tests too" # a message for its agent
fleet status task fix-login --json       # status.result once the agent records one
fleet delete task fix-login              # stop it and remove its worktree

The agent reports its answer with fleet result, which fills status.result. fleet attach fix-login prints the command that opens its terminal, and fleet --help lists every command. Next: how Fleet works, and the Thurbox interface to watch every session at once.
