Get started with Thurbox

Thurbox is the terminal interface on top of Fleet. You need tmux (psmux on Windows), git, and a coding-agent CLI that is installed and logged in (Agents).

1. Install # 

curl -fsSL https://raw.githubusercontent.com/Thurbeen/thurbox/main/scripts/install.sh | sh

This installs thurbox, thurbox-cli and Fleet. Windows and the packages are on Install.

2. Launch it # 

thurbox-cli doctor   # checks each Fleet, its runtime and its agents
thurbox

On a machine with no Fleet config, the first thurbox runs fleet init and says where it wrote the config, then starts Fleet's manager. The session list is on the left and the agent terminal on the right.

3. Create a first session #

Press Ctrl+N. Pick the place (local is this machine), add a repository with Tab, give it a worktree with Alt+W, name the session, and pick an agent. Enter creates it: a Fleet Task, with the agent running in the right pane. Everything you type goes to it.

4. The keys you need #

Key Action
Ctrl+NNew session
Ctrl+J / Ctrl+KNext / previous session
Ctrl+H / Ctrl+LMove focus between panes
Ctrl+/Search sessions and their screens
F1Every key, rebindable
Ctrl+QQuit; every agent keeps running
