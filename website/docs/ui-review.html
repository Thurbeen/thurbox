warning
Meter rows are hard to decode at panel width visual
Memory (191.1 MB), a CPU bar at ~20% and a disk bar render as very short progress bars in a narrow column; the bars carry little information and the values sit apart from them.
Fix: Right-align the numeric value next to each bar and add a unit/threshold so the row is self-describing.
nit
"not logged in (no subscription token)" reads as an error usability
The Usage line is shown in the same weight as data rows and can alarm a user who is in fact authenticated via the system keyring.
Fix: Soften the copy ("usage unavailable — no token") and visually demote it so it reads as 'no data'.

File viewer (repo tree) Ctrl+E

nit
File viewer opens to an expanded top level (resolved) usability
The viewer now opens with each root's first level expanded — `docs`, `tests`, `README.md` are visible immediately — instead of a single collapsed folder that read as empty.
Fix: Done. Expansion is bounded to the top level so the rebuild stays cheap.
nit
File-viewer footer hints are densely packed visual
The viewer footer crams move / collapse-expand / open / search / next-prev into one line of small dim text, which is hard to parse mid-task.
Fix: Group the hints by purpose (navigate | open | search) with subtle separators, or show only the subset relevant to the current focus.

Theme picker Ctrl+Y

warning
Theme preview swatch is too small to evaluate visual
The picker lists nine themes with a tiny Accent/Status/Border/Modal-bg swatch block; the swatches are only a few cells each, so you cannot really preview a theme before selecting it.
Fix: Enlarge the swatch into a labeled palette strip, or live-apply the highlighted theme to the background TUI as a true preview while navigating.

Light themes are tagged "(Light)" inline but dark themes carry no tag, so the dark/light split is inferred rather than grouped.

New-session / repo picker Ctrl+N

warning
Empty repo picker is a dead end for new users usability
The picker opens to "Repos (0) · No bookmarks — add via path input below" with an empty input; a first-run user with no bookmarks gets a near-blank modal and must already know to type a path.
Fix: Seed the picker with recently-used repos or the current working directory, and give the path input a focused placeholder example.
