Install Fleet

Fleet needs fleet and a runtime on your PATH. The installer ships runtime-mux, the runtime that runs its sessions, and workspace-git, its workspace provider; either can be replaced by your own (Places and runtimes). To use Fleet with thurbox, follow thurbox's installation instead: it installs both.

Prerequisites #

  • tmux >= 3.2, or psmux >= 3.3.8 on native Windows: runtime-mux runs each session in one
  • git: the worktrees the runtime makes
  • A coding-agent CLI, installed and logged in, that Fleet has a harness profile for

Fleet alone # 

curl -fsSL https://raw.githubusercontent.com/Thurbeen/thurbox/main/scripts/install.sh | sh -s -- --fleet-only
fleet init
fleet doctor
fleet up

The installer's fleet-only mode puts fleet, runtime-mux and workspace-git in ~/.local/bin, and nothing else. On Windows, pass -FleetOnly through a script block: 

& ([scriptblock]::Create((irm https://raw.githubusercontent.com/Thurbeen/thurbox/main/scripts/install.ps1))) -FleetOnly

Nothing updates a fleet-only install: to update it, run the installer again.

To move a Fleet 2 install to Fleet 3, reinstall, then run fleet migrate: see Migrating from v2.

Then create your first Task: Get started.

Keep fleet up running #

On a machine you do not sit at, run fleet up as a user systemd service. Then sessions come back after a reboot, without a login. A user service does not read your login PATH: name the directories that hold fleet, runtime-mux, tmux and your coding agents. KillMode=process keeps the tmux server that fleet up starts, and every session on it, when the unit stops or restarts. 

[Unit]
Description=Fleet manager

[Service]
Environment=PATH=%h/.local/bin:/usr/local/bin:/usr/bin:/bin
ExecStart=%h/.local/bin/fleet up
KillMode=process
Restart=on-failure
RestartSec=15

[Install]
WantedBy=default.target
loginctl enable-linger "$USER"
systemctl --user enable --now fleet.service

thurbox can follow this Fleet from another machine over ssh; see Fleets.

From source #

From a clone of the repository (its rust-toolchain.toml picks the toolchain):

cargo install --locked --path crates/fleet-cli --bin fleet
cargo install --locked --path crates/runtime-mux
cargo install --locked --path crates/workspace-git
