Install Fleet

Fleet needs fleet and a runtime on your PATH. The installer ships runtime-mux, the runtime that runs its sessions in tmux, runtime-herdr, which runs them in herdr (Fleet in herdr), and workspace-git, its workspace provider; each can be replaced by your own (Places and runtimes). To use Fleet with thurbox, follow thurbox's installation instead: it installs both.

Prerequisites #

  • tmux >= 3.2, or psmux >= 3.3.8 on native Windows: runtime-mux runs each session in one
  • git: the worktrees the runtime makes
  • A coding-agent CLI, installed and logged in, that Fleet has a harness profile for

Fleet alone # 

curl -fsSL https://raw.githubusercontent.com/Thurbeen/thurbox/main/scripts/install.sh | sh -s -- --fleet-only
fleet init
fleet doctor
fleet up

The installer's fleet-only mode puts fleet, runtime-mux, runtime-herdr and workspace-git in ~/.local/bin, and nothing else. On Windows, pass -FleetOnly through a script block: 

& ([scriptblock]::Create((irm https://raw.githubusercontent.com/Thurbeen/thurbox/main/scripts/install.ps1))) -FleetOnly

Nothing updates a fleet-only install: to update it, run the installer again.

Then create your first Task: Get started.

Keep fleet up running #

On a machine you do not sit at, run fleet up as a user service. On Linux with a systemd user session, the installer already did this. Otherwise, fleet service install --now writes the service, records your current PATH, enables the service and starts it. A user service does not read your login PATH: run it from a shell whose PATH holds fleet, runtime-mux, tmux and your coding agents. 

fleet service install --now

On Linux, enable lingering so that sessions come back after a reboot, without a login. On macOS (a launchd agent) and on Windows (a Task Scheduler task), the service starts when you log in. 

loginctl enable-linger "$USER"

thurbox can follow this Fleet from another machine over ssh; see Fleets.

From source #

From a clone of the repository (its rust-toolchain.toml picks the toolchain):

cargo install --locked --path crates/fleet-cli --bin fleet
cargo install --locked --path crates/runtime-mux
cargo install --locked --path crates/runtime-herdr
cargo install --locked --path crates/workspace-git
