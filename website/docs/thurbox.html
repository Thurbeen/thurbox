What is thurbox

thurbox is a terminal interface on top of one or more Fleets. It shows every session of every Fleet in one list, with the agent's live terminal beside it, and lets you create, switch, message and delete sessions from the keyboard.

  • Fleet runs the sessions. thurbox keeps no session state: every session is a Fleet Task. Quit thurbox and the agents keep running.
  • One list, several Fleets. Follow a Fleet on this machine and others over ssh or WSL, listed in ~/.config/thurbox/settings.toml (Fleets).
  • The interface is yours. Every pane, the session list included, is a Lua file you can move, turn off, replace or write (The interface).

First steps #

  1. Install thurbox. The install script installs Fleet with it.
  2. Run thurbox. On a machine with no Fleet config, it runs fleet init first, and it starts fleet up on this machine when no manager runs.
  3. Press Ctrl+N: pick a place, a repository, a name and an agent. The tutorial walks through it.

What thurbox keeps #

Only how you look at things: session order, seen marks, bookmarks, theme, keybindings and settings, as plain files under ~/.config/thurbox/ and ~/.local/share/thurbox/. Everything about a session is Fleet's. thurbox-cli covers the interface's own files: doctor, config, plugin, ui, version and more.
