Orchestrate agents

Fleet runs your coding agents and keeps them running. thurbox is the terminal interface to watch and drive them.

Fleet thurbox

The engine

Fleet

Fleet runs coding-agent sessions. Each session is a Task: a file that names the agent, the place it runs, the repository and the brief. You apply it with fleet apply, and Fleet starts the session, keeps it running, delivers your messages and records the result.

Fleet works on its own. It is headless and needs no thurbox.

What Fleet is → Fleet features → 

fleet apply -f fix-login.json
fleet list task
fleet send fix-login "Run the tests too"

Get started with Fleet alone

curl -fsSL https://raw.githubusercontent.com/Thurbeen/thurbox/main/scripts/install.sh | sh -s -- --fleet-only
fleet init
fleet doctor
fleet up

--fleet-only installs fleet, runtime-mux and workspace-git, and nothing else. It needs a 3.x release: until one is published, the script installs the latest 2.x, which has no Fleet. Install Fleet →

The interface

thurbox

thurbox is a terminal interface on top of one or more Fleets. It shows every session of every Fleet in one list, with the agent's live terminal beside it. Every pane is a Lua file you can move, turn off or replace.

Quit thurbox and the agents keep running: Fleet runs them.

Get started with thurbox

curl -fsSL https://raw.githubusercontent.com/Thurbeen/thurbox/main/scripts/install.sh | sh
thurbox

The first thurbox runs fleet init and starts Fleet on this machine. On Windows, run irm https://raw.githubusercontent.com/Thurbeen/thurbox/main/scripts/install.ps1 | iex. Other install routes →

Plugins to start from

  • thurbox-info-panel Session, git, agent, account quota and system readouts beside the terminal.
  • thurbox-code-review A Review tab: the session's diff against its base branch, with notes sent to the agent.
  • thurbox-auto-continue When a Claude Code session hits its usage limit, waits for the reset and continues.
  • thurbox-fleetlens Fleet Lens: browse Fleet's Tasks and other resources in a read-only float.
  • thurbox-doom DOOM as a tab of the agent pane.

How they fit

thurbox follows one or more Fleets, on this machine or over ssh or WSL; each Fleet's runtime runs the sessions at a place.
